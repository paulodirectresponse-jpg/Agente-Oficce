# Office visual assets

The files in `public/office-assets/` were imported from the public repository `ashawareb/the-office`.

The source project credits the furniture and interior tiles to **bitglow — Pixel Interior**, released under **CC0** (public domain / commercial use allowed).

Only the CC0 furniture and interior tile sheets are reused here. Character sprites from that project are intentionally not included.

Source: https://github.com/ashawareb/the-office
